# Рабочая структура

## Изоляция

| Компонент | Новый проект | «Политикан» |
| --- | --- | --- |
| Telegram | отдельный публичный канал и бот | не используется |
| GitHub | отдельный репозиторий и секреты | не используется |
| Данные | отдельная SQLite-база и очередь | не используется |
| Панель | отдельный GitHub Pages-сайт | не используется |

## Поток материала

1. Планировщик запускает сбор официальных источников в облаке.
2. Сборщик принимает только разрешённые домены и сохраняет оригинальные реквизиты.
3. Валидатор проверяет ссылку, дату, дедлайн, тип возможности и отсутствие дубля.
4. Отдельный переводчик готовит русский заголовок; оригинал остаётся источником истины. Бесплатный MyMemory используется только для коротких английских заголовков, учитывается в отдельной таблице и никогда не передаёт материал в «Политикан».
5. Материал попадает в очередь со статусом `review`.
6. Только проверенная карточка может быть запланирована к публикации.
7. Публикация и ошибки фиксируются в журнале и видны на панели.

## Режимы безопасности

- `disabled` — сбор и публикация отключены.
- `review` — материалы собираются, но не публикуются автоматически.
- `auto` — доступен лишь после тестов и подтверждения реквизитов.

Начальное значение: `disabled`.
