# Европа | Учёба • Карьера • Работа

Самостоятельный проект русскоязычного Telegram-канала об официальных европейских возможностях обучения, стажировок, работы, грантов и программ мобильности.

## Принципы

- Проект полностью изолирован от «Политикана»: отдельные код, доступы, очередь, база, GitHub Actions и панель.
- В публикацию допускаются только материалы с проверяемым официальным первоисточником.
- Публикуются русские краткие выжимки и ссылка на оригинал; полные тексты не копируются.
- Автоматизация работает в облаке, но публикация включается только после проверок реквизитов, источников и тестового режима.

## Контур

`официальные источники → нормализация → перевод → валидация → очередь → проверка → Telegram`

Состояние очереди и результаты запусков будут отображаться в отдельной панели контроля.

## Статус запуска

Созданы отдельные публичный канал, бот и GitHub-репозиторий. Реализованы изолированная очередь, проверка официальных источников, тестовый отправитель и ежечасная облачная проверка.

Переводчик полностью отделён от «Политикана». Бесплатный путь MyMemory повторяет только его архитектурную идею, но имеет свой модуль, свою таблицу учёта и свои пределы: переводятся лишь короткие английские заголовки, до 4 000 символов в сутки, а результат должен пройти проверку русского текста и качества. Ключи, если в будущем понадобится заменить провайдера, будут храниться только в Secrets нового репозитория — не в коде, логах или панели.

Очередь переводится отдельной командой `scripts/translate_review_titles.py`: без `--apply` это только проверка, с `--apply` она меняет лишь русский заголовок карточки со статусом `review`. Она не имеет доступа к Telegram и не может опубликовать материал.

Автопубликация остаётся выключенной: обязательная предварительная проверка не разрешит тестовую отправку, пока у бота не подтверждено право публикации именно в этом канале. Первый адаптер EURAXESS уже читает только прямые ссылки с официального сайта и пока работает в режиме проверки, без добавления материалов в очередь.
