# Европа | Учёба • Карьера • Работа

Изолированный проект Telegram-канала об официальных европейских возможностях учёбы, стажировок, карьеры и работы.

## Стартовые гарантии

- Отдельные Telegram-канал, репозиторий, очередь и конфигурация; «Политикан» не используется.
- Только официальные, проверяемые первоисточники.
- Автопубликация отключена до завершения проверок реквизитов, источников и облачного запуска.
- Очередь защищена от дублей и не может публиковать напрямую.
- Журнал операций не принимает секреты и токены.
